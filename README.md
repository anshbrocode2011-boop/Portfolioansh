# Ansh — Video Editor Portfolio (React + Tailwind)

Starter project (Vite + React + Tailwind) for a dark-futuristic, glassmorphism portfolio.

Quick commands:
- Install: npm install
- Dev: npm run dev
- Build: npm run build
- Preview build: npm run preview

Add projects: edit src/data/projects.js

Contact form: mailto fallback included. Replace with an API (SendGrid, Formspree, Netlify Forms) for production.
